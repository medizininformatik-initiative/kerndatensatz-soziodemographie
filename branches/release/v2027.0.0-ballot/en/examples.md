### Examples

This Implementation Guide includes example instances for all profiles.

**Patient**

* [MII EXA SDD Patient](Patient-mii-exa-sdd-patient.md) - Beispiel-Patient, auf den sich die Beispiel-Erhebungen dieses Moduls beziehen

**Datenerhebung**

* [MII EXA SDD Datenerhebung](Observation-mii-exa-sdd-datenerhebung.md) - Sammel-Beobachtung, die alle Einzelerhebungen der Soziodemographie für einen Patienten referenziert

**Herkunft**

* [MII EXA SDD Geburtsland Mutter](Observation-mii-exa-sdd-geburtsland-mutter.md) - Geburtsland der Mutter der Patientin/des Patienten
* [MII EXA SDD Geburtsland Vater](Observation-mii-exa-sdd-geburtsland-vater.md) - Geburtsland des Vaters der Patientin/des Patienten

**Lebenssituation**

* [MII EXA SDD Betreuungssituation](Observation-mii-exa-sdd-betreuungssituation.md) - Aktuelle Betreuungssituation
* [MII EXA SDD Haushaltsgroesse](Observation-mii-exa-sdd-haushaltsgroesse.md) - Anzahl der Personen, die ständig im Haushalt der Person leben
* [MII EXA SDD Partnerschaft](Observation-mii-exa-sdd-partnerschaft.md) - Aktuelle Partnerschaft der Person
* [MII EXA SDD Schwerbehindertenausweis](Observation-mii-exa-sdd-schwerbehindertenausweis.md) - Vorliegen eines Schwerbehindertenausweises mit Grad der Behinderung und Merkzeichen
* [MII EXA SDD Vertrauensperson](Observation-mii-exa-sdd-vertrauensperson.md) - Existenz mind. einer Vertrauensperson

**Soziooekonomische Faktoren**

* [MII EXA SDD Soziooekonomische Faktoren](Observation-mii-exa-sdd-soziooekonomische-faktoren.md) - Generische Beobachtung eines sozioökonomischen Faktors
* [MII EXA SDD Ausbildung](Observation-mii-exa-sdd-ausbildung.md) - Höchster beruflicher Ausbildungsabschluss
* [MII EXA SDD Berufliche Stellung](Observation-mii-exa-sdd-berufliche-stellung.md) - Berufliche Stellung der hauptsächlich ausgeübten Erwerbstätigkeit
* [MII EXA SDD Beschäftigungsstatus](Observation-mii-exa-sdd-beschaeftigungsstatus.md) - Aktuell hauptsächlich ausgeübte Tätigkeit
* [MII EXA SDD Einkommen](Observation-mii-exa-sdd-einkommen.md) - Durchschnittliches monatliches Nettoeinkommen des Haushalts
* [MII EXA SDD Schulabschluss](Observation-mii-exa-sdd-schulabschluss.md) - Höchster erreichter allgemeinbildender Schulabschluss
* [MII EXA SDD Schuljahre](Observation-mii-exa-sdd-schuljahre.md) - Anzahl der Jahre, in denen insgesamt eine Schule besucht wurde
