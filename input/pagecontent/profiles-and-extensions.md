### Profiles

The following profiles have been defined for this implementation guide.

**Datenerhebung**

* [MII PR SDD Datenerhebung](StructureDefinition-mii-pr-sdd-datenerhebung.html) - Datenerhebung für SDD

**Herkunft**

* [MII PR SDD Geburtsland Mutter](StructureDefinition-mii-pr-sdd-geburtsland-mutter.html) - Geburtsland der Mutter
* [MII PR SDD Geburtsland Vater](StructureDefinition-mii-pr-sdd-geburtsland-vater.html) - Geburtsland des Vaters des Patienten

**Lebenssituation**

* [MII PR SDD Lebenssituation](StructureDefinition-mii-pr-sdd-lebenssituation.html) - Lebenssituation des Patienten (abstrakt)

* [MII PR SDD Schwerbehindertenausweis](StructureDefinition-mii-pr-sdd-schwerbehindertenausweis.html) - Vorliegen eines Schwerbehindertenausweises des Patienten
* [MII PR SDD Vertrauensperson](StructureDefinition-mii-pr-sdd-vertrauensperson.html) - Existenz mind. einer Person, der die Person uneingeschränkt vertrauen und mit der die Person persönliche Dinge besprechen kann

**Soziooekonomische Faktoren**

* [MII PR SDD Berufliche Stellung](StructureDefinition-mii-pr-sdd-berufliche-stellung.html) - Berufliche Stellung der hauptsächlich ausgeübten Erwerbstätigkeit
* [MII PR SDD Beschäftigungsstatus](StructureDefinition-mii-pr-sdd-beschaeftigungsstatus.html) - Aktuell hauptsächlich ausgeübte Tätigkeit
* [MII PR SDD Einkommen](StructureDefinition-mii-pr-sdd-einkommen.html) - Durchschnittliches monatliches Nettoeinkommen des Haushalts
* [MII PR SDD Schulabschluss](StructureDefinition-mii-pr-sdd-schulabschluss.html) - Höchster erreichter allgemeinbildender Schulabschluss (Langversion)
* [MII PR SDD Schuljahre](StructureDefinition-mii-pr-sdd-schuljahre.html) - Anzahl der Jahre, in denen insgesamt eine Schule besucht wurde, inkl. Besuch einer Berufs- oder Hochschule (Minimalversion)
