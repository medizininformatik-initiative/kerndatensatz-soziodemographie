Für diesen Implementierungsleitfaden wurden die folgenden Profile definiert.

**Datenerhebung**

* [MII PR SDD Datenerhebung](StructureDefinition-mii-pr-sdd-datenerhebung.html) - Datenerhebung für SDD

**Herkunft**

* [MII PR SDD Geburtsland Mutter](StructureDefinition-mii-pr-sdd-geburtsland-mutter.html) - Geburtsland der Mutter
* [MII PR SDD Geburtsland Vater](StructureDefinition-mii-pr-sdd-geburtsland-vater.html) - Geburtsland des Vaters des Patienten

**Lebenssituation**

* [MII PR SDD Lebenssituation](StructureDefinition-mii-pr-sdd-lebenssituation.html) - Abstraktes Basisprofil: legt die Vorgaben, die für alle folgenden Profile der Lebenssituation gelten (Kategorien, Patientenbezug, Erhebungszeitpunkt, dataAbsentReason), einmal zentral fest. Es wird nicht direkt instanziiert; Instanzen entsprechen immer einem der abgeleiteten Profile.
* [MII PR SDD Betreuungssituation](StructureDefinition-mii-pr-sdd-betreuungssituation.html) - Aktuelle Betreuungssituation
* [MII PR SDD Haushaltsgroesse](StructureDefinition-mii-pr-sdd-haushaltsgroesse.html) - Anzahl der Personen, die ständig im Haushalt der Person leben
* [MII PR SDD Partnerschaft](StructureDefinition-mii-pr-sdd-partnerschaft.html) - Aktuelle Partnerschaft der Person
* [MII PR SDD Schwerbehindertenausweis](StructureDefinition-mii-pr-sdd-schwerbehindertenausweis.html) - Vorliegen eines Schwerbehindertenausweises des Patienten
* [MII PR SDD Vertrauensperson](StructureDefinition-mii-pr-sdd-vertrauensperson.html) - Existenz mind. einer Person, der die Person uneingeschränkt vertrauen und mit der die Person persönliche Dinge besprechen kann

**Soziooekonomische Faktoren**

* [MII PR SDD Soziooekonomische Faktoren](StructureDefinition-mii-pr-sdd-soziooekonomische-faktoren.html) - Abstraktes Basisprofil: legt die Vorgaben, die für alle folgenden sozioökonomischen Profile gelten (Kategorien, Patientenbezug, Erhebungszeitpunkt, dataAbsentReason), einmal zentral fest. Es wird nicht direkt instanziiert; Instanzen entsprechen immer einem der abgeleiteten Profile.
* [MII PR SDD Ausbildung](StructureDefinition-mii-pr-sdd-ausbildung.html) - Höchster beruflicher Ausbildungsabschluss
* [MII PR SDD Berufliche Stellung](StructureDefinition-mii-pr-sdd-berufliche-stellung.html) - Berufliche Stellung der hauptsächlich ausgeübten Erwerbstätigkeit
* [MII PR SDD Beschäftigungsstatus](StructureDefinition-mii-pr-sdd-beschaeftigungsstatus.html) - Aktuell hauptsächlich ausgeübte Tätigkeit
* [MII PR SDD Monatliches Einkommen](StructureDefinition-mii-pr-sdd-monatliches-einkommen.html) - Durchschnittliches monatliches Nettoeinkommen des Haushalts
* [MII PR SDD Schulabschluss](StructureDefinition-mii-pr-sdd-schulabschluss.html) - Höchster erreichter allgemeinbildender Schulabschluss (Langversion)
* [MII PR SDD Schuljahre](StructureDefinition-mii-pr-sdd-schuljahre.html) - Anzahl der Jahre, in denen insgesamt eine Schule besucht wurde, inkl. Besuch einer Berufs- oder Hochschule (Minimalversion)
